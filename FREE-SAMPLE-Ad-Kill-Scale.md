## The four rules (the whole system in 30 seconds)

1. **RULE 1 — Zero conversions at 2× target CPA spend → KILL.**
2. **RULE 2 — CPA above 3× target CPA → KILL.**
3. **RULE 3 — CPA at or below target CPA → SCALE.**
4. **RULE 4 — Everything else → KEEP TESTING.**

Target CPA = the most you can pay for one customer and still make money.
Break-even CPA = AOV × gross margin. Break-even ROAS = 1 ÷ gross margin.

## Mini worked example (FICTIONAL numbers)

Setup (FICTIONAL): target CPA **$25**, AOV **$80**, gross margin **40%**.
Break-even CPA = $80 × 40% = **$32.00**. Rule 1 kill line = **$50**. Rule 2 line = **$75**.

| Ad set (FICTIONAL) | Spend | Conv. | CPA | Rule | Verdict |
|---|---|---|---|---|---|
| Ad Set 1 | $60 | 0 | — | RULE 1: $60 ≥ $50 with 0 conv. | **KILL** |
| Ad Set 2 | $40 | 0 | — | RULE 4: only $40 spent, below the $50 kill line | KEEP TESTING |
| Ad Set 3 | $90 | 2 | $45 | RULE 4: CPA $45 is between $25 and $75 | KEEP TESTING |
| Ad Set 4 | $120 | 1 | $120 | RULE 2: $120 > $75 | **KILL** |
| Ad Set 5 | $50 | 3 | $16.67 | RULE 3: $16.67 ≤ $25 | **SCALE** |

Ad Set 3 *feels* expensive ($90 for 2 sales) but the math says "not enough
evidence to kill." Ad Set 4 *feels* promising ("it got a sale!") but $120 per
customer against a $25 target is a Rule 2 kill, no debate.
